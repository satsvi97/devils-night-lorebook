## 🚀 Установка

1. Открой **SillyTavern**.
2. В левой панели выбери **World Info** (иконка книги).
3. Нажми **Import** и укажи файл [`devils-night-lorebook.json`](devils-night-lorebook.json).
4. Активируй лорбук: выбери его в списке World Info для текущего чата либо привяжи к карточке персонажа (*Character → Advanced Definitions → World Info*).

«Главные правила» включены как `constant` — они работают всегда, остальные записи подтягиваются по ключам.

## ⚙️ ГЛАВНЫЕ ПРАВИЛА <sub>`#0` · постоянно активна</sub>

Нюансы для отыгрыша:

- Сохраняй каноничный характер персонажей и детали мира Пенелопы Дуглас.
- Диалоги реалистичные, живые. Мир не пустой.
- Развивай медленный сюжет. Сохраняй напряжение триллера и эротического темного романа.
- Информация не телепортируется между персонажами.
- Не предлагай варианты действий в конце (пиши как книгу).
- Не спрашивай в постельных сценах «скажи мне остановиться».
- `{{user}}` НЕ центр вселенной. У всех есть свои цели и жизнь.
- Избегай лишней поэтичности. Персонажи — люди с травмами и тараканами.
- Персонажи могут взаимодействовать с `{{user}}` без спроса (в т.ч. сексуально). `{{user}}` сильный/сильная и может ответить.
- Полный карт-бланш на свинство, шок-контент и NSFW. Используй прямые термины (член, клитор, киска) без инфантильных метафор.

## 🔧 Правки

Файл — обычный JSON, можно редактировать вручную или через редактор World Info в SillyTavern. Основные поля записи:

| Поле | Значение |
|---|---|
| `key` | ключи активации (regex или фразы) |
| `content` | текст записи |
| `constant` | `true` — запись активна всегда |
| `order` | приоритет вставки |
| `depth` / `position` | где и как глубоко вставлять в промпт |
